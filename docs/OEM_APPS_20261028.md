## CarPlay: información interna identificada, acceso externo pendiente

ZLink contiene librerías nativas `libzlink_metadata.so` y `libcast_core.so`. Sus símbolos y cadenas legibles identifican callbacks CP de título/artista/álbum, portada, duración, posición y guía de ruta. También hay callbacks JNI `onCpMediaItemAttributesChange`, `onCpMediaPlayBackAttributesChange`, `onCpRouteGuidanceUpdateChange` y `onCpRouteManeuverUpdateChange` en el módulo HUD. Son evidencia de formatos internos de esta compilación, no de una API Android disponible para un launcher externo, ni de recepción efectiva en este equipo.

La configuración vendor leída tiene `enable_hud: false` por defecto y el bloque `ceres` no lo sobrescribe. No se cambió esa configuración ni se infiere que sea la única condición que controla el canal. La biblioteca de metadata contiene un cliente de socket a `127.0.0.1`; faltan contrato de conexión, ciclo de vida, compatibilidad y autorización para un consumidor externo. No se abrieron sockets del equipo ni se cargaron sus librerías.

El servicio Android antes observado mantiene descriptor `IPhoneContentPresenter`, pero los DEX visibles de ZLink solo contienen el wrapper y BuildConfig/R. El APK completo de Tema también tiene un wrapper: cuatro clases visibles; no aporta la implementación de escritorio. No se intentó sortear esas protecciones ni adivinar transacciones.

## Qué falta para continuar con CarPlay

Un contrato compatible de ZLink 6.1.06 para Android API 29 / DINGWEI-A133: callbacks de metadata/portada/tiempo y, por separado, una superficie de vídeo con entrada táctil para un APK normal. La documentación oficial de [Android zLink](https://zjinnova.com/android-zlink.html) ofrece documentos y soporte de integración mediante contacto técnico; no confirma que este firmware permita entregar esas capacidades a terceros.

Se preparó una [solicitud técnica](ZLINK_VENDOR_REQUEST.md) para el vendedor/fabricante. No se envió ningún mensaje a terceros. La nueva entrega continúa retenida por instrucción del usuario; este análisis no acredita CarPlay integrado ni sustituye su validación física.
